# Dasuni Nethmini — Portfolio

A personal portfolio featuring UI/UX design, software and mobile projects, and event invitation designs.

Built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Deploy on Vercel

Import this repository into Vercel and select the Vite framework preset.

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## Update content

- Project information and contact details: `src/pages/Portfolio.jsx`
- Project screenshots and design images: `public/projects/`
- Portfolio styles: `src/pages/Portfolio.css`
